- 수치 계약: `passed`, 113개 특성 / 101766행.

- 임의 최소표본수/통계유의성 기준을 만들지 않았습니다. 각 블록의 상세 근거·집계·한계는 `eda.json`에 있습니다.

## 사용자 선택과 승인
교육용 계획 승인 준비: **미완료**.
- AI pending/stale 또는 planning_complete 미완료입니다.
- 선택 목록에 포함된 명시적인 primary_metric이 필요합니다.

PR의 Conversation에 아래와 같이 `/plan` 명령만 별도 댓글로 작성합니다. 다음 값은 사용법 예시이며 자동 적용되지 않습니다.

```text
/plan add eda prediction_timing
/plan add evaluation f1
/plan primary average_precision
/plan threshold 0.3
```

제외는 `/plan remove eda|evaluation ID`, 매개변수는 `/plan parameter top_fraction 0.1`, AI 재추천은 `/plan recommend`를 사용합니다.

일반 댓글·인용·코드블록은 선택을 바꾸지 않습니다. 처리된 댓글을 고치지 말고 새 명령 댓글을 작성하세요.
AI 추천 provided, 주지표 선택, blocked 평가 항목 없음 상태를 확인한 뒤 Ready for review → Merge합니다. 실패·대기 상태로 병합하면 승인 기록을 만들지 않습니다.
사람이 Merge한 시점의 선택·계획·자산·해시를 `research/approved/`에 새 불변 기록으로 보존합니다.
이 승인은 교육용 계획 확정이며 모델 실행·최종 평가·임상 사용 승인이 아닙니다.
